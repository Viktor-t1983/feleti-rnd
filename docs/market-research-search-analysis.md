# Анализ альтернатив SearXNG для поиска производителей

## Проблема
SearXNG имеет критический баг с кодировкой UTF-8 при выдаче результатов в формате JSON/HTML (кракозябры вместо русского текста).

## ТОП-3 альтернативы с GitHub (>1000 ⭐)

### 🥇 #1 - Whoogle Search ⭐ 11,425
**GitHub:** https://github.com/benbusby/whoogle-search

| Параметр | Значение |
|----------|----------|
| **Язык** | Python 3.11 |
| **Архитектура** | Google proxy (не metasearch) |
| **Русский язык** | ✅ Полная поддержка |
| **Docker** | ✅ One-click deployment |
| **API** | ✅ JSON endpoint |

**Плюсы:**
- Очень простой деплой (1 контейнер)
- Чистые результаты Google без рекламы/JS/cookies
- Встроенная поддержка Tor и прокси
- Быстрый (только Google, нет overhead)
- Поддержка bangs (!wikipedia, !github и т.д.)

**Минусы:**
- ⚠️ Только Google как источник (нет Яндекса, Bing, etc.)
- ⚠️ Google активно блокирует без-JS поиск (риск в 2025)
- Нет агрегации из множества источников

**Оценка для FELETI:** 7/10
- Хорош для быстрого старта
- Риск блокировки Google

## 💡 Рекомендации для FELETI

### Вариант А: Whoogle (быстрое решение) ✅ РЕКОМЕНДУЕТСЯ
**Почему:**
1. Работает с русским языком из коробки
2. Деплой за 5 минут
3. Google даёт лучшие результаты для B2B/промышленности
4. Надёжнее SearXNG в текущем состоянии

**Настройка:**
```yaml
services:
  whoogle:
    image: benbusby/whoogle-search:latest
    container_name: feleti-whoogle
    ports:
      - "8081:5000"
    environment:
      - WHOOGLE_DOTENV=1
      - WHOOGLE_CONFIG_LANGUAGE=lang_ru
      - WHOOGLE_CONFIG_SEARCH_LANGUAGE=russian
      - WHOOGLE_CONFIG_THEME=dark
```

### Вариант Б: Serper.dev (продакшн-решение) ✅ ЛУЧШЕЕ
**Почему:**
1. Официальный Google Search API
2. 100% надёжность
3. Нет проблем с кодировкой
4. Готовые структурированные данные

**Цена:** $50/мес за 50K запросов

### Вариант В: Оставить SearXNG + костыль
Принять кодировку как есть и делать decode на фронтенде:
```javascript
// Декодирование в AiBlockAssistant
const decoded = decodeURIComponent(escape(text));
```
