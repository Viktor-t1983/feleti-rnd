# Техническое задание: Система поиска производителей оборудования

## 1. Общие сведения

**Проект:** FELETI R&D - маркетплейс промышленного оборудования  
**Задача:** Поиск производителей/поставщиков оборудования по запросу пользователя  
**География:** Беларусь, Россия, Казахстан (приоритет), также Китай, Турция, Европа

## 2. Функциональные требования

### 2.1 Базовый поиск
- [ ] Поиск по типу оборудования ("фаршмешалка", "волчек промышленный")
- [ ] Фильтрация по странам (BY, RU, KZ, CN, TR, PL, DE)
- [ ] Возврат: название компании, сайт, описание, страна
- [ ] Количество результатов: минимум 20-30 уникальных компаний

### 2.2 Источники поиска (приоритеты)
1. **Поисковые системы** (обязательно)
   - Google или агрегаторы (DuckDuckGo, Bing)
   - Яндекс (критично для РФ/Беларуси)
   
2. **B2B площадки** (желательно)
   - Deal.by (Беларусь)
   - Tiu.ru, Pulscen.ru (Россия)
   - Alibaba.com (Китай)
   - 1688.com (Китай)

3. **Отраслевые каталоги** (опционально)
   - Промышленные выставки
   - Торгово-промышленные палаты

### 2.3 Технические требования

#### Обязательные:
- [ ] **Работа в России** - Google заблокирован, нужны альтернативы
- [ ] **UTF-8 поддержка** - русский язык без кракозябр
- [ ] **API endpoint** - JSON REST API для интеграции
- [ ] **Скорость** - ответ < 10 секунд
- [ ] **Rate limiting** - минимум 1000 запросов/сутки

#### Желательные:
- [ ] **Дедупликация** - убирать дубликаты по домену
- [ ] **Кэширование** - хранить результаты 7-30 дней
- [ ] **Fallback** - если один источник упал, работают другие
- [ ] **Бесплатно или дешево** - бюджет до $50/мес

## 3. Варианты решений (что искать)

### Вариант А: Self-hosted метапоиск
**Примеры:** SearXNG, Whoogle, YaCy
- Плюсы: бесплатно, приватность
- Минусы: требует сервера, настройки, может ломаться

### Вариант Б: API поисковиков
**Примеры:**
- Яндекс XML API (yandex.ru/dev/xml/) - 1000 бесплатно/сутки
- Bing Web Search API - 1000 бесплатно/мес
- Serper.dev - $50/мес за 50K запросов (Google)
- DuckDuckGo API - бесплатно, но неофициально

### Вариант В: Парсеры B2B площадок
**Примеры:**
- Прямой парсинг deal.by, tiu.ru
- ScrapingBee, ScrapingAnt (прокси для парсинга)

### Вариант Г: Гибридное решение
- Комбинация нескольких источников
- Fallback между ними

## 4. Критерии выбора

| Критерий | Вес | Описание |
|----------|-----|----------|
| Работа в РФ | 10/10 | Критично, Google недоступен |
| UTF-8 русский | 10/10 | Должен корректно показывать кириллицу |
| Бесплатно/дешево | 8/10 | Бюджет ограничен |
| Надежность | 8/10 | Минимум простоев |
| Скорость | 7/10 | < 10 сек на запрос |
| Легкость интеграции | 7/10 | REST API, документация |

## 5. Что уже пробовали
