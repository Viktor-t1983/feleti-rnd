## 🔧 ВЫЯВЛЕННЫЕ ПРОБЛЕМЫ

### 1. E2E тесты - конфигурация URL

**Проблема:** Playwright тесты настроены на `localhost:5173` (dev server), но production frontend работает на порту 80.

**Решение:** Обновить `apps/web/playwright.config.ts`:

```typescript
use: {
  baseURL: process.env.CI
    ? 'http://localhost' // Docker production
    : 'http://localhost:5173'; // Dev server
}
```

### 2. Rate limiting на auth endpoint

**Проблема:** При частых запросах к /api/auth/login срабатывает rate limiter (8 минут блокировки).

**Статус:** Ожидаемое поведение для безопасности.
